# Método Heap Sort

Projeto com implementação de Heap Sort por construção de heap máximo.

## Objetivos

- Praticar estrutura heap para ordenação
- Entender a relação pai-filho em representação de heap
- Aplicar ajustes sucessivos durante a ordenação

## Funcionalidades

- Construir heap máximo a partir do array
- Reposicionar elementos com heapify
- Ordenar array por extração do maior elemento
- Exibir o progresso das trocas no terminal

## Tecnologias Usadas

- C++
- Algoritmos de ordenação
- Eclipse IDE

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `18-metodo-heapsort` no terminal
3. Compile com: `g++ .\src\main.cpp -o app.exe`
4. Execute com: `\.\app.exe`
