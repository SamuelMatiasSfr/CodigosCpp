# Árvores Binárias

Projeto de árvore binária implementada com representação em array.

## Objetivos

- Praticar implementação de árvore binária com array
- Inserir nós à esquerda e à direita usando o nó pai como referência
- Testar inserção de valores na árvore binária

## Funcionalidades

- Definir valor da raiz da árvore
- Inserir no filho esquerdo de um nó pai
- Inserir no filho direito de um nó pai
- Imprimir a representação da árvore no terminal

## Tecnologias Usadas

- C++
- Programação Orientada a Objetos
- Estruturas de dados (Árvore Binária)
- Eclipse IDE

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `11-arvores-binarias` no terminal
3. Compile com: `g++ .\src\main.cpp -o app.exe`
4. Execute com: `\.\app.exe`
5. Para comparar visualmente, insira os mesmos valores no simulador indicado em `Descrição da tarefa.txt`
