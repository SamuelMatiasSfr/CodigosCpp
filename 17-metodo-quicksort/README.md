# Método Quick Sort

Projeto com implementação do algoritmo Quick Sort usando particionamento recursivo.

## Objetivos

- Praticar ordenação por divisão e conquista
- Entender a estratégia de pivoteamento

## Funcionalidades

- Definir pivô para particionamento
- Reorganizar elementos em torno do pivô
- Ordenar subarrays recursivamente
- Exibir etapas de troca durante a ordenação

## Tecnologias usadas

- C++
- Algoritmos de ordenação
- Eclipse IDE

## Como Executar

### Requisitos
- Ter o compilador `g++` instalado e configurado no PATH

### Execução
1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `17-metodo-quicksort` no terminal
3. Compile com: `g++ .\src\main.cpp -o app.exe`
4. Execute com: `.\app.exe`
