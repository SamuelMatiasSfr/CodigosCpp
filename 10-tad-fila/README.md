# TAD Fila

Projeto com implementação de fila e operações básicas de estrutura FIFO.

## Objetivos

- Praticar implementação de TAD fila
- Aplicar lógica FIFO em inserção e remoção
- Testar operações essenciais de consulta da estrutura

## Funcionalidades

- Inserir elemento no fim da fila
- Remover elemento do início da fila
- Consultar elementos armazenados
- Limitar quantidade máxima de elementos na estrutura

## Tecnologias Usadas

- C++
- Programação Orientada a Objetos
- Estruturas de dados (Fila)
- Eclipse IDE

## Como Executar

### Requisitos
- Ter o compilador `g++` instalado e configurado no PATH

### Execução
1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `10-tad-fila` no terminal
3. Compile com: `g++ .\src\main.cpp .\src\Fila.cpp -o app.exe`
4. Execute com: `.\app.exe`
