# Método Shell Sort

Projeto com implementação do algoritmo Shell Sort e exibição de trocas durante a ordenação.

## Objetivos

- Praticar o algoritmo Shell Sort
- Entender o uso de gaps para reduzir deslocamentos
- Visualizar etapas de troca durante o processamento

## Funcionalidades

- Gerar valores para teste de ordenação
- Ordenar vetor de inteiros com Shell Sort
- Ordenar string com Shell Sort
- Exibir trocas realizadas durante a execução

## Tecnologias usadas

- C++
- Algoritmos de ordenação
- Eclipse IDE

## Como executar

1. Baixe e extraia este repositorio para uma pasta local
2. Abra o terminal (PowerShell) na pasta extraida do repositorio
3. Entre na pasta do projeto com: `cd 16-metodo-shellsort`
4. Compile com: `g++ .\src\main.cpp -o app.exe`
5. Execute com: `.\app.exe`
