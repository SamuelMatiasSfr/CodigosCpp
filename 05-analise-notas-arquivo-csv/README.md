# 05 - Analise de Notas em Arquivo CSV

Projeto para ler dados de alunos em CSV e calcular medias por subturma.

## Objetivos

- Praticar manipulação de arquivos CSV
- Trabalhar com agrupamento de dados por categoria

## Funcionalidades

- Ler arquivo CSV de alunos
- Extrair campos de cada linha de dados
- Agrupar alunos por subturma
- Calcular média de notas por subturma
- Exibir os resultados no terminal

## Tecnologias usadas

- C++
- Manipulação de arquivos CSV

## Como executar

1. Baixe e extraia este repositorio para uma pasta local
2. Abra o terminal (PowerShell) na pasta extraida do repositorio
3. Entre na pasta do projeto com: `cd 05-analise-notas-arquivo-csv`
4. Compile com: `g++ .\src\main.cpp -o app.exe`
5. Execute com: `.\app.exe`
6. Se quiser testar volume maior, ajuste no codigo para usar `alunos1000.csv`
