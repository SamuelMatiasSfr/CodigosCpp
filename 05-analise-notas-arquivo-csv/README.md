# Análise de Notas em Arquivo CSV

Projeto para ler dados de alunos em CSV e calcular medias por subturma.

## Objetivos

- Praticar manipulação de arquivos CSV
- Trabalhar com agrupamento de dados por categoria

## Funcionalidades

- Ler arquivo CSV de alunos
- Extrair campos de cada linha de dados
- Agrupar alunos por subturma
- Calcular média de notas por subturma
- Exibir os resultados no terminal

## Tecnologias Usadas

- C++
- Eclipse IDE

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `05-analise-notas-arquivo-csv` no terminal
3. Compile com: `g++ .\src\main.cpp -o app.exe`
4. Execute com: `\.\app.exe`
5. Se quiser testar volume maior, ajuste no código para usar `alunos1000.csv`
