# Métodos de Seleção e Inserção

Projeto com implementação dos algoritmos de ordenação por seleção e por inserção.

## Objetivos

- Praticar algoritmos clássicos de ordenação
- Entender o funcionamento de seleção e inserção em arrays
- Aplicar ordenação em números e strings

## Funcionalidades

- Ordenar vetor de inteiros por seleção
- Ordenar string por seleção
- Ordenar vetor de inteiros por inserção
- Ordenar string por inserção
- Exibir arrays antes e depois da ordenação

## Tecnologias Usadas

- C++
- Algoritmos de ordenação
- Eclipse IDE

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `15-metodos-selecao-insercao` no terminal
3. Compile com: `g++ .\src\main.cpp -o app.exe`
4. Execute com: `\.\app.exe`
