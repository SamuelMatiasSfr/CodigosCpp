# Ponteiros

Projeto com exercícios de ponteiros, aritmética de ponteiros e leitura de dados.

## Objetivos

- Praticar sintaxe e semântica de ponteiros
- Aplicar aritmética de ponteiros em arrays
- Trabalhar com memória e acesso indireto a dados

## Funcionalidades

- Calcular média de valores por ponteiro
- Percorrer array usando aritmética de ponteiros
- Ler e manipular dados a partir de arquivo
- Testar exercícios propostos em funções separadas

## Tecnologias Usadas

- C e C++
- Eclipse IDE

## Como Executar

### Requisitos
- Ter o compilador `g++` instalado e configurado no PATH

### Execução
1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `20-ponteiros` no terminal
3. Compile com: `g++ .\src\main.cpp -o app.exe`
4. Execute com: `.\app.exe`
5. Se houver leitura de arquivo nos testes ativos, mantenha `dados.csv` na pasta do projeto
