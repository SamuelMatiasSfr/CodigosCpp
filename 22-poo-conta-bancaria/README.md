# POO Conta Bancária

Projeto de conta bancária com classe dedicada, encapsulamento e namespace.

## Objetivos

- Praticar encapsulamento de atributos e métodos
- Aplicar organização de código em múltiplos arquivos
- Utilizar namespace para agrupar classes 

## Funcionalidades

- Criar objeto de conta bancária
- Ler dados da conta por métodos de acesso
- Atualizar dados da conta por métodos modificadores
- Exibir conta em formato textual
- Executar rotinas de questões no arquivo principal

## Tecnologias Usadas

- C++
- Programação Orientada a Objetos
- Eclipse IDE

## Como Executar

### Requisitos
- Ter o compilador `g++` instalado e configurado no PATH

### Execução
1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `22-poo-conta-bancaria` no terminal
3. Compile com: `g++ .\src\main.cpp .\src\ContaBancaria.cpp -o app.exe`
4. Execute com: `.\app.exe`
