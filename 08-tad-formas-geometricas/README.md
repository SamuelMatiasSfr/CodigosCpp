# TAD Formas Geométricas

Projeto com TADs para formas 3D (Cubo e Cilindro), calculando área e volume.

## Objetivos

- Praticar definição de TAD com cabeçalho e implementação
- Trabalhar com encapsulamento em classes

## Funcionalidades

- Definir TAD de Cubo
- Definir TAD de Cilindro
- Calcular área e volume de cubo
- Calcular área e volume de cilindro
- Exibir resultados dos cálculos no terminal

## Tecnologias Usadas

- C++
- Programação Orientada a Objetos
- Eclipse IDE

## Como Executar

### Requisitos
- Ter o compilador `g++` instalado e configurado no PATH

### Execução
1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `08-tad-formas-geometricas` no terminal
3. Compile com: `g++ .\src\main.cpp .\src\Cubo.cpp .\src\Cilindro.cpp -o app.exe`
4. Execute com: `.\app.exe`
