# TAD Stack

Projeto com implementação de pilha e operações adicionais sobre a estrutura.

## Objetivos

- Praticar implementação de TAD pilha
- Aplicar operações clássicas de estrutura LIFO
- Desenvolver operações compostas entre pilhas

## Funcionalidades

- Inserir elemento no topo da pilha
- Remover elemento do topo da pilha
- Consultar elemento do topo
- Reunir duas pilhas em uma pilha final
- Dividir uma pilha em duas metades
- Somar os elementos da pilha

## Tecnologias usadas

- C++
- Programação Orientada a Objetos
- Estruturas de dados (Stack/Pilha)

## Como executar

1. Baixe e extraia este repositorio para uma pasta local
2. Abra o terminal (PowerShell) na pasta extraida do repositorio
3. Entre na pasta do projeto com: `cd 09-tad-stack`
4. Compile com: `g++ .\src\main.cpp .\src\Stack.cpp .\src\Aluno.cpp -o app.exe`
5. Execute com: `.\app.exe`
