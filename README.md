# Códigos em C++

Estes projetos foram desenvolvidos como atividades práticas da matéria Linguagem e Técnicas de Programação I no curso técnico de informática do CEFET-MG.

## Objetivos

- Praticar lógica de programação
- Aprender fundamentos de programação em C e C++
- Desenvolver raciocínio lógico e domínio de estruturas de dados e algoritmos clássicos
- Aplicar orientação a objetos em cenários práticos com classes, encapsulamento e namespaces
- Trabalhar com leitura e escrita de arquivos texto e CSV para tratamento de dados
- Implementar miniaplicações gráficas e jogos simples com SFML

## Tecnologias Usadas

- C e C++
- Programação Orientada a Objetos
- SFML
- Estruturas de dados clássicas (pilha, fila e árvores)
- Algoritmos de ordenação
- Eclipse IDE

## Como Executar

### Requisitos
- Ter o compilador `g++` instalado e configurado no PATH
- (Para projetos gráficos) Ter a SFML instalada e configurada (include, lib e DLLs)

> **Observação:**  
> Os tutoriais utilizam o compilador `g++` como exemplo padrão.  Os projetos podem ser compilados com outros compiladores, porém podem ser necessárias adaptações nos comandos de compilação, configuração de bibliotecas (como a SFML) e no ambiente de desenvolvimento.

### Execução
1. Baixe e extraia o arquivo `.zip` com os projetos
2. Siga as instruções específicas no `README.md` do projeto

## Projetos

- `01-manipulacao-arquivos`: busca uma palavra em arquivo de texto e realiza substituição por outra.
- `02-manipulacao-arquivos`: analisa palavras de um arquivo e identifica termos longos.
- `03-array-matrizes`: pratica operações com matrizes e leitura de dados em arquivo.
- `04-sfml-eventos-mouse`: explora eventos de mouse com SFML e movimentação de objeto na tela.
- `05-analise-notas-arquivo-csv`: lê CSV de alunos e calcula médias por subturma.
- `06-poo-classes-objetos`: trabalha classes e objetos com exemplos de classe `Pessoa`.
- `07-poo-simulador-movimento`: simula movimento de objetos móveis com base em posição e velocidade.
- `08-tad-formas-geometricas`: implementa TADs para cubo e cilindro com cálculos geométricos.
- `09-tad-stack`: implementa pilha e operações como reunir, dividir e somar elementos.
- `10-tad-fila`: implementa fila com operações básicas de inserção e remoção.
- `11-arvores-binarias`: implementa árvore binária em array e testes de inserção.
- `12-sfml-chuvagame`: cria jogo em SFML com coleta de gotas, obstáculos e pontuação.
- `13-sfml-alocacao-dinamica-bolas`: une alocação dinâmica com simulação gráfica de bolas.
- `14-namespaces`: organiza código em múltiplos arquivos com uso de namespaces.
- `15-metodos-selecao-insercao`: implementa ordenação por seleção e inserção.
- `16-metodo-shellsort`: implementa Shell Sort com visualização de trocas.
- `17-metodo-quicksort`: implementa Quick Sort com particionamento recursivo.
- `18-metodo-heapsort`: implementa Heap Sort com construção e ajuste de heap.
- `19-arvore-pesquisa-binaria`: implementa árvore de pesquisa binária para diferentes tipos.
- `20-ponteiros`: reúne exercícios práticos de ponteiros e aritmética de ponteiros.
- `21-poo-manipulacao-arquivos-vectors`: analisa dados de GPUs em CSV com classes e vetores.
- `22-poo-conta-bancaria`: implementa classe de conta bancária com encapsulamento e namespace.
