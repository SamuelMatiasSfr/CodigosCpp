# POO Classes e Objetos

Projeto de orientacao a objetos com classe Pessoa e leitura de dados em CSV.

## Objetivos

## Objetivos

- Praticar Programação Orientada a Objetos em C++
- Praticar definição de classes e atributos
- Trabalhar com construção e uso de objetos

## Funcionalidades

## Funcionalidades

- Definir classe Pessoa com atributos principais
- Criar objetos por diferentes construtores
- Exibir dados dos objetos no terminal
- Ler registros de pessoas a partir de arquivo CSV
- Armazenar objetos em coleção para processamento

## Tecnologias usadas

## Tecnologias usadas

- C++
- Programação Orientada a Objetos
- Manipulação de arquivos CSV

## Como executar

1. Baixe e extraia este repositorio para uma pasta local
2. Abra o terminal (PowerShell) na pasta extraida do repositorio
3. Entre na pasta do projeto com: `cd 06-poo-classes-objetos`
4. Compile com: `g++ .\src\main.cpp -o app.exe`
5. Execute com: `.\app.exe`
6. Mantenha `dados.csv` na pasta do projeto para executar os testes de leitura
