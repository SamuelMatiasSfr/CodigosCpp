# POO Manipulação de Arquivos com Vetores

Projeto para ler dados de GPUs em CSV e encontrar opções com menor valor por fabricante.

## Objetivos

- Praticar modelagem de dados com classes
- Trabalhar com leitura de CSV e processamento em coleção

## Funcionalidades

- Ler arquivo CSV com dados de GPUs
- Criar objetos de GPU a partir das linhas do arquivo
- Filtrar dados por fabricante
- Identificar GPU de menor valor por fabricante
- Exibir resultados no terminal

## Tecnologias usadas

- C++
- Programação Orientada a Objetos
- Eclipse IDE

## Como executar

1. Baixe e extraia este repositório para uma pasta local
2. Abra o terminal (PowerShell) na pasta extraída do repositório
3. Entre na pasta do projeto com: `cd 21-poo-manipulacao-arquivos-vectors`
4. Compile com: `g++ .\src\main.cpp -o app.exe`
5. Execute com: `.\app.exe`
6. Mantenha `gpus.csv` na pasta do projeto para carregar os dados
