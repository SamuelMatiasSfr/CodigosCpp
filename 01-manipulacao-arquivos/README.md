# Manipulação de Arquivos

Projeto para buscar uma palavra em um arquivo de texto e substituir por outra.

## Objetivos

- Praticar leitura e escrita de arquivos de texto  
- Trabalhar com strings em C++

## Funcionalidades

- Ler um arquivo de texto informado pelo usuário  
- Procurar ocorrências de uma palavra em cada linha  
- Contar a quantidade de ocorrências encontradas  
- Substituir a palavra buscada por uma nova palavra  
- Salvar o resultado da substituição no arquivo  

## Tecnologias Usadas

- C++  
- Eclipse IDE

## Como Executar

1. Baixe e extraia o arquivo `.zip` do repositório
2. Entre na pasta `01-manipulacao-arquivo` no terminal  
3. Compile com: `g++ .\src\main.cpp -o app.exe`  
4. Execute com: `.\app.exe`  
5. Informe no terminal o nome do arquivo e as palavras para busca/substituição
